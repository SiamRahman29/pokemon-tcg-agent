THE DESIGN -- optimal allocation for the SAME weighted precision
  (±0.0050 on W), by Neyman allocation with costs:

  anchor                  n per arm      games
  mirror (grimmsnarl)        15,800     15,800
  rule:v10 (M Lucario)        1,900      3,800
  rule:archaludon             3,600      7,200
  rule:alakazam5              8,500     17,000
  rule:dragapult              2,000      4,000
  bc:garchomp                 2,200      4,400
  rule:crustle (v4)           2,700      5,400
  TOTAL                                 57,600
  = 2.7 h single-process, 1.1 h at 2-3 jobs -- 55% of the equal-n cost for the same precision.
  ⚠ These n are for ONE variant.  A search over k variants costs k
    times this, minus the control arms, which are shared.

WHAT STRATIFICATION BUYS -- and it is NOT precision:
  Spend the same 57,600 games mirror-only and Delta_mirror is
  measured to ±0.0041, i.e. BETTER than the
  stratified design's ±0.0050 on W.
  Every game in one cell beats games spread over seven.
  ⇒ 🔴 The case for stratifying is entirely about BIAS.  Mirror-only
    estimates W by assuming Delta is the same in every matchup, and
    §8al showed that assumption failing by construction: Tool
    Scrapper is played 0.00 times per mirror game and drawn in 81% of
    real games, so a mirror A/B returns 'cutting it is free' however
    many games you buy.  A more precise estimate of the wrong
    quantity is worse, not better -- it is rule 16 with a tighter CI.
  ⇒ So a variant is stratified when its cards are matchup-specific,
    and measured mirror-only when they are not.  Deciding which is a
    LIVENESS question, per card per matchup, and that instrument does
    not exist yet.  It is the next build, not this one.

DOES A REAL DIFFERENCE COMPRESS THE WAY THE ELO MODEL SAYS? (§8an)
  Same three nets, one anchor, two pilot versions of different
  difficulty.  If the Elo model holds, a net-vs-net difference should
  shrink by the ratio of p(1-p) between the two pilots.

  pair       at p~.78  predicted   observed    SE(obs)
  v4-v3        0.0185     0.0121     0.0080     0.0119
  v5-v4       -0.0205    -0.0134    -0.0090     0.0119

  ⚠ READ THE LAST COLUMN BEFORE THE OTHERS.  Both observed values sit
    well inside one SE of both the prediction and of zero, so this
    CANNOT distinguish the Elo model from any other.  It is reported
    because it is the only empirical handle available and because
    'we checked and it was underpowered' is the honest verdict --
    not because it confirms anything.  The design below therefore
    rests on the arithmetic above, which needs no model of how
    effects compress: it is stated in win-rate units throughout.
