## 3. The shared instrument — stated once, referenced by every cell

E25 + E26 left a **general-purpose scoreboard**, and it is this round's biggest
inherited asset. Any method that changes the shipped policy's picks reports
**(realised changed-picks/game, score)** and is placed on the cost law:

```
incoherent deviation   -0.11148 log-odds per changed pick   (E25, replicated out-of-sample by E26 cell B)
a trained policy       -0.01899 log-odds per changed pick   (E26 cell A)
f = (method - rate-matched coin flip) / (0.500 - coin flip)
```

Reference points: `f_eval = 0.12` (the evaluator family), `f_coh = 0.758`
(a trained policy's deviations).

**Three rules that come with it, each paid for:**

1. ⚠ **Read the REALISED value of the variable you claim varied, from the run's
   own logs** — a knob is not a variable (three instances in three sessions).
   Any cell that changes picks reports its realised rate, or it reports nothing.
2. ⚠ **Key every reading rule on the COMPARISON, not on one arm** — E25's own
   branch condition fired correctly for a reason its condition did not establish.
3. ⚠ **`val_top1` may neither promote nor kill a candidate.** Agreement is a
   conformity metric; a perfect score on it is compatible with being modal, and
   modal is ~1000.
